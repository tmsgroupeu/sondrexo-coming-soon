SONDREXO — UNDER-DEVELOPMENT LANDING PAGE
==========================================

WHAT'S INCLUDED
- index.html             Main responsive landing page (HTML/CSS; no JS required)
- assets/sondrexo-logo.png   Transparent version of the supplied logo
- assets/harbor-sunset.webp Optimized maritime sunset background
- assets/harbor-sunset.jpg  JPEG background alternative
- assets/favicon.png       Brand icon

HOW TO PUBLISH
1. Upload index.html and the 'assets' folder to your website's public
   directory (e.g. public_html on Hostinger or your web host).
2. Keep the same file names and folder structure.
3. Open your domain to see the page. The contact button opens your visitor's
   default email application addressed to sales@sondrexo.com.

CUSTOMIZATION
- Email: search for sales@sondrexo.com in index.html
- Headline / message: change the HTML inside <main>
- Background image: replace assets/harbor-sunset.webp with a new WEBP file.
- Image animation: edit the 'cinematic-drift' CSS animation in index.html.

NOTES
- Background and logo are separate image files; all text and the CTA are
  real selectable, accessible HTML, not baked into a screenshot.
- Fonts load from Google Fonts where available and fall back to system fonts.
- Respect for the user's reduced-motion preference is built in.
